# 发布安全与使用边界

公开内容仅为 Skill、安装/打包工具、说明和虚构练习。没有模型 API 客户端、后台服务、分析统计或外部上传逻辑。以下扫描结果记录首版发布的检查范围；后续版本应重新检查变动文件、Git 历史和 ZIP，不能沿用旧版结果宣称已经通过。

- 文件与 Git 提交历史使用 Gitleaks 8.30.1 默认规则扫描，不使用仓库自定义豁免。
- ZIP 单独解包扫描，并逐项核对清单和 SHA-256。
- 手工复核文档、SVG、示例与脚本：无真实名单、私有共享链接、凭据、Cookie、本机个人路径；Git 提交使用 GitHub noreply 邮箱。
- 安装器只处理显式目标目录中的本技能；不联网、不改模型配置、不读取用户的本组配置。已有个人改动和未知来源同名技能会导致安装停止。
- 模拟表只绑定 127.0.0.1；运行状态写入系统临时目录。不把它当成可公开部署的服务。

扫描只能覆盖已检查的版本和已知规则，不能保证发现所有敏感信息。工作时请勿把真实配置、审核记录或账号截图提交到仓库、Issue、PR 或发布包。

0.1.1（2026-10-30）已重新检查变动文件、可用 Git 历史和单独解包的 ZIP，Gitleaks 默认规则未命中密钥；另检查真实姓名、私有链接、客户端地址与本机个人路径未进入本次变动。没有新增媒体或外部依赖；未发布用户提供的界面截图。该检查属于发布内容检查，不代表网页操作已受技术权限限制。

## 0.1.1 的表格写入限制

Skill 中的“只改这些格”是指令，不是技术上的权限隔离。自动回填要求外部机制阻止越界写入：保护范围对当前执行账号有效，或受限工具在每次写入前检查本次文档、页签、允许单元格与 ✅／❌，且不存在可绕过的通用写入路径。不能把管理员自己仍可编辑的保护范围视为有效限制。

本包没有实现受限浏览器、表格代理或权限管理服务，也不会自动配置文档权限。无法核实边界时，只读核对和生成待回填清单。禁止仅靠截图坐标向 Canvas 输入区域地址或测试文字；出现非预期修改立即停写并报告，不能自行尝试整表撤销或修复。[完整规则](../skills/daily-work-review/references/write-safety.md)。

2026-10-30 的失败记录只保留概括后的问题与修正，不发布原始账号界面、会话内容、真实姓名、共享链接或客户端地址。安装和文件脱敏检查也不能代替真实表格回填的可靠性验证。
