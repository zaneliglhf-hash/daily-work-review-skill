# 每日作品审核 Skill

给执行器一份可复用的审核规则：核对提交、读作品、用原表选项填写 ✅／❌，生成可复制的中文汇报。**审核日期就是目标作品日期，不减一天。**

## ① 首次：复制这段话给你的执行器

```text
请从 https://github.com/zaneliglhf-hash/daily-work-review-skill
安装「每日作品审核」Skill。

先阅读仓库 INSTALL.md，根据当前执行器支持的方式，下载并安装
skills/daily-work-review 的完整内容和引用文件。
核对文件完整性，并检查技能是否已被执行器识别。
然后检查你能否操作登录后的网页、读取作品和填写表格，
如缺少能力请如实告诉我，不要声称已完成在线审核。
安装完成后展示「审核链接、审核日期、本次审核人」三个填写项。
这一步只安装和检查，不启动真实审核。
```

执行器需要有联网下载和文件/技能安装能力。不能自动安装时，下载 [Skill ZIP](dist/daily-work-review.zip)，在工具的技能管理页面导入。ZIP 不附带模型或浏览器。

## ② 日常：引用 Skill，填三项

```text
使用「每日作品审核」Skill。

审核链接：
审核日期：2026-10-28
本次审核人：

请核对提交情况、填写审核表，并生成完整审核汇报。
```

- **审核链接**：第一次可在这一项粘贴提交表和审核表两个链接；只给一个时，执行器先寻找另一张表的入口，找不到再问。同组配置可以保存在自己的工作空间，下次写“沿用本组配置”。
- **审核日期**：填哪天就审核哪天，报告标题使用同一天。实际执行日期由工具读取，“明日审核人”取原表轮值中当前审核人的下一位。
- **本次审核人**：填写自己的姓名，不是要点评的作者。

默认核对全员，按表中顺序点评五位不同作者。可补充“本次点评：@同学甲 @同学乙”，仍然核对全员。遇到登录提示，由你扫码后继续；结果生成后自行复制发群。

## 你会得到什么

```text
10月28日审核同步

未完成人员名单；@姓名

作品1 @作者
这篇帖子的优点是……；缺点是……。

明日审核人：@姓名
审核情况：原审核表链接
```

以上仅为格式示意，不是真实审核结果。执行器另附已核验、待核对和未完成的步骤；读不到原文就不编造点评，缺交证据不完整就不填 ❌。

## 实际演练

![虚构审核表，原生选项回填后刷新核验](assets/demo-table.png)

独立执行器在本机虚构表上核对 8 人、读取 5 篇全文并回填，刷新后保留 6 个 ✅、2 个 ❌，前一天未改动。[查看实际生成的示例汇报](examples/sample-report.txt)。这是模拟表验证，不代表微信文档适配已通过。

## 支持情况与边界

标准 Skill 不代表所有聊天软件都能安装或控制网页。有网页操作能力的执行器可尝试完整流程；只能读材料的 AI 会要求提供完整名单、提交记录、正文/图片，并明确标注“未在线核验、未回填”。
