# 每日作品审核 Skill

给执行器一份可复用的审核规则：核对提交、读作品、用原表选项填写 ✅／❌，生成可复制的中文汇报。**审核日期就是目标作品日期，不减一天。**

**0.1.1 回填限制：Skill 是操作规则，不是权限系统。** 只有确认表格权限或受限写入工具能阻止当前执行器修改本次允许范围之外的内容，才允许自动回填。无法确认时，执行器完成读取、点评和汇报，并给出逐人待回填清单，不修改原表。不能仅靠截图坐标向 Canvas 表格输入文字或区域地址。[查看写入边界](skills/daily-work-review/references/write-safety.md)。

## ① 首次：复制这段话给你的执行器

```text
请从 https://github.com/zaneliglhf-hash/daily-work-review-skill
安装「每日作品审核」Skill。

先阅读仓库 INSTALL.md，根据当前执行器支持的方式，下载并安装
skills/daily-work-review 的完整内容和引用文件。
核对文件完整性，并检查技能是否已被执行器识别。
然后检查你能否操作登录后的网页、读取作品，以及是否有受限回填能力，
如缺少能力请如实告诉我，不要声称已完成在线审核。
安装完成后展示「审核链接、审核日期、本次审核人」三个填写项。
这一步只安装和检查，不启动真实审核。
```

**0.1.0 已在 WorkBuddy 5.9.3 验证安装和识别。2026-10-30 用户真实试用反馈出现误写，完整回填未通过；0.1.1 真实表复测待完成。** 安装成功不能证明回填安全。[查看验证范围](docs/verification.md)。

执行器需要有联网下载和文件/技能安装能力。不能自动安装时，下载 [Skill ZIP](dist/daily-work-review.zip)，在工具的技能管理页面导入。ZIP 不附带模型或浏览器。

已经安装旧版的同学，请在新任务中复制：

```text
这一步只更新和检查，不打开、修复或填写任何审核表，也不恢复先前中断的任务。
```

## ② 日常：引用 Skill，填三项

```text
使用「每日作品审核」Skill。

审核链接：
审核日期：2026-10-28
本次审核人：

请核对提交情况、填写审核表，并生成完整审核汇报。
```

- **审核链接**：第一次可在这一项粘贴提交表和审核表两个链接；只给一个时，执行器先寻找另一张表的入口，找不到再问。同组配置可以保存在自己的工作空间，下次写“沿用本组配置”。
- **审核日期**：填哪天就审核哪天，报告标题使用同一天。实际执行日期由工具读取，“明日审核人”取原表轮值中当前审核人的下一位。
- **本次审核人**：填写自己的姓名，不是要点评的作者。

默认核对全员，按表中顺序点评五位不同作者。可补充“本次点评：@同学甲 @同学乙”，仍然核对全员。遇到登录提示，由你扫码后继续；结果生成后自行复制发群。

## 你会得到什么

```text
10月28日审核同步

未完成人员名单；@姓名

作品1 @作者
这篇帖子的优点是……；缺点是……。

明日审核人：@姓名
审核情况：原审核表链接
```

以上仅为格式示意，不是真实审核结果。执行器另附已核验、待核对和未完成的步骤；读不到原文就不编造点评，缺交证据不完整就不填 ❌。

0.1.0 的独立执行器在本机虚构表上核对 8 人、读取 5 篇全文并回填，刷新后保留 6 个 ✅、2 个 ❌，前一天未改动。[查看当时生成的示例汇报](examples/sample-report.txt)。这是旧版模拟表验证，不代表微信文档适配或 0.1.1 的写入边界已通过验证。

## 支持情况与边界

标准 Skill 不代表所有聊天软件都能安装或控制网页。能操作浏览器也不等于能安全回填：还需核实范围限制确实对当前执行账号生效，或由不能绕过的受限工具检查文档、页签、单元格及允许值。未具备该边界时只读并输出待回填清单。只能读材料的 AI 会要求提供完整名单、提交记录、正文/图片，并明确标注“未在线核验、未回填”。
