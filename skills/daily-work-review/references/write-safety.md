# 表格操作边界

打开真实共享表前阅读本文件。它限制定位、复制等读取操作以及回填操作；“先读取”不能成为往单元格输入区域地址的理由。

## 1. 本次允许改什么

先以只读方式建立本次写入白名单，每个条目包含：文档标识、页签标识、用户明确填写的审核日期、姓名、唯一目标格/记录字段、现值、拟选原有选项及提交证据。目标必须同时匹配日期和姓名；没有可靠定位的条目不进入白名单。不硬编码某天的列号、姓名行号或前次坐标。

仅允许已核实人员在目标日期下的状态格，且值仅限原有 `✅` 或 `❌`。以下全部在边界外：年月选择、日期表头、标题、姓名、其他日期、公式、行列与页签结构、格式和验证规则、共享筛选、排序、权限设置。不得为了方便审核而修改它们。

日期列不存在、重名无法定位、原值冲突、记录不全时保留原值，说明需要核实的信息。用户说“审核并填表”授权的是明确的业务回填，不包括测试、改模板、取消保护或修复其他内容。

## 2. 自动写入的前提

白名单写在提示词或本地 JSON 里，只是计划，不是权限控制。自动回填真实表必须同时满足：

1. **外部限制生效**：有可核实的表格权限，使当前执行账号不能修改本次可写状态格之外的内容；或使用专用写入工具，由工具/服务校验文档、页签、目标格和允许的原有选项，拒绝越界请求。仅验证计划后仍让模型自由点击可编辑浏览器，不算限制生效。工具路线中，其他可绕过限制的通用写入通道必须不可用。
2. **目标可绑定**：操作工具能确认当前文档、页签、日期、姓名与控件对应的唯一目标格，并能选择该格现有选项。坐标看起来正确、截图比例换算正确、焦点似乎在名称框，都不能替代这种确认。只有截图坐标的 Canvas 操作不满足自动回填条件。
3. **保存可复核**：能读取写前现值并刷新读取写后结果；能够核对姓名、日期表头等边界外关键字段。

从实际执行账号的权限视图或已验证的工具契约核实限制，不用在真实表的禁止区域试写来测试。表格所有者或管理员可能仍有编辑权，不能因为设置了保护范围就推定本账号已受限。普通编辑权限、“允许完全访问”、逐步确认开关以及 Skill 安装成功都不是单元格范围保护。

任一前提未确认，就进入只读模式，继续可安全完成的阅读和点评，输出固定汇报与单独的待回填清单，不反复请求用户用一句“继续”绕过限制。说明：“已完成可读取部分；未核实安全回填条件，原表未回填。”本技能不安装保护插件、不自动改表权限，也不声称自带受限写入服务。

## 3. 逐格回填与停止条件

1. **读取基线**：记录目标状态格现值、姓名列与相关日期/年月表头。使用可靠的只读 API、导出、记录详情或原生复制；不向名称框、公式栏或表格键入区域地址。只能靠焦点猜测才能复制时，停止该读取方式。不得用输入文字来检查是否可编辑。
2. **重新核对**：每次操作前重新绑定白名单条目的文档、页签、日期、姓名、格标识和现值。滚动、缩放、布局变化、排序或协作者修改后，先重新读取，旧定位不能继续使用。已有值一致则跳过；不同则重新核实补交/并发修改，仍冲突时保留原值。
3. **选择真实结果**：首格指第一个实际需要修改的格；已正确的格跳过，全部一致时不写入，仅刷新核对。首格必须是白名单内、证据充分的真实业务结果，使用原有下拉/单选选项。禁止任何测试字符串、临时值、普通文字键入、粘贴整列、删除内容或通过快捷键到某格试写。使用保护范围也不豁免这些规则。
4. **先核验首格**：刷新后重读首格、对应姓名、相关日期/年月表头。结果一致且未见边界异常再继续；后续逐格选择并读回，完成后刷新复核全部已写目标格及基线字段。没有读取到的范围不能声称未受影响。不批量使用通用键盘或剪贴板写入。
5. **第一次异常就停写**：目标/焦点不确定、现值变化、非预期内容、边界外变化、选项不匹配或保存状态不明，立即停止所有表格写操作。无副作用读取的重试规则不适用于写入；不继续校准坐标、不盲目重试、不接着完成剩余人员。
6. **如实交付**：报告有证据的已保存格、未保存/状态不明格、待核对人员及边界异常。若允许继续只读核查，可保留最小证据；用户要求“不再动表”或接管浏览器时，暂停全部表格与浏览器操作，包括读取和自动修复。

## 4. 发现误改以后

只报告已知事实：哪些位置发生变化、哪些原值有事前证据、哪些范围尚未核实。不能把执行器自己的事后解释当成全表核验结果，也不能猜测丢失原值。

本次审核不自动恢复误改，不连续撤销、不整表版本回退；共享表可能已有其他人的新修改。提供逐格恢复建议，由用户决定是否处理。用户另外明确要求修复时，将它作为独立任务，重新核实当前值、原值证据和可靠操作路径；普通“继续审核”不代表允许绕过上述边界。

## 5. 待回填清单

放在固定汇报之外，按原名册顺序列出“姓名｜审核日期｜已核实的目标格（没有则写未定位）｜原值｜拟选状态｜原因”。只在可安全读取时取原值，未知值不猜。待核对人员写“保留原值”，不提供 ❌。清单仅供核对/人工使用，不是声称已回填的证据，也不能直接作为整列粘贴指令。
