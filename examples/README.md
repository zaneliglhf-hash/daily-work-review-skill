# 虚构演练

这里全部为虚构人物与短文，不是真实审核。`fixture.json` 是离线练习材料，`server.py` 提供仅绑定本机的模拟表。

```text
python3 examples/server.py --port 8877
```

在有浏览器能力的执行器中使用已安装技能，填写：

```text
审核链接：http://127.0.0.1:8877/audit
审核日期：2026-10-28
本次审核人：同学丙
请核对全员，点评可读作品并使用已有选项填表，刷新后验证。
```

这是模拟网页，仅验证规则和交互流程，不能证明已适配微信文档 Canvas、登录、验证码或社交平台。

状态只保存在临时运行目录，停服务后不进入仓库；再次启动是新表。不要用真实数据替换本例后提交 GitHub。
