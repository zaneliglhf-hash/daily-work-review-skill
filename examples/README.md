# 虚构演练

这里全部为虚构人物与短文，不是真实审核。`fixture.json` 是离线练习材料，`server.py` 提供仅绑定本机的模拟表。

```text
python3 examples/server.py --port 8877
```

在有浏览器能力的执行器中使用已安装技能，填写：

```text
审核链接：http://127.0.0.1:8877/audit
审核日期：2026-10-28
本次审核人：同学丙
请核对全员，点评可读作品并使用已有选项填表，刷新后验证。
```

这是模拟网页，仅供虚构数据演练，不能证明已适配微信文档 Canvas、登录、验证码或社交平台。仓库截图及 sample-report.txt 是 0.1.0 的历史演练结果。

模拟服务没有实现按执行账号限制范围的权限系统，不能用它证明 0.1.1 的真实表写入边界已生效。测试新版的拒绝写入行为时，应明确将其作为“未核实外部范围限制”的情景，预期为只读审核及待回填清单；不要把它换成真实链接试写。

状态只保存在临时运行目录，停服务后不进入仓库；再次启动是新表。不要用真实数据替换本例后提交 GitHub。
